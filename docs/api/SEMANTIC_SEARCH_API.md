# Semantic Search API Documentation

## Overview

Universal Memory MCP v0.4.0 introduces semantic search capabilities using vector embeddings. This enables finding relevant content based on meaning, not just keyword matching.

## Quick Start

```typescript
import {
  VectorStore,
  IndexingPipeline,
  createDefaultEmbeddingProvider,
  semanticSearch,
  hybridSearch,
} from 'universal-memory-core'

// Initialize
const provider = createDefaultEmbeddingProvider()
const vectorStore = new VectorStore({
  storagePath: '~/.ai_memory',
  dimensions: provider.dimensions,
})

// Index your conversations
const pipeline = new IndexingPipeline(vectorStore, provider, storagePath)
await pipeline.indexRecent(7) // Last 7 days

// Search
const results = await semanticSearch('authentication implementation', {
  embeddingProvider: provider,
  vectorStore: vectorStore,
  limit: 10,
})
```

## Core Concepts

### 1. Embedding Provider

Generates vector representations of text.

```typescript
import {
  GeminiEmbeddingProvider,
  OpenAIEmbeddingProvider,
  createDefaultEmbeddingProvider,
} from 'universal-memory-core'

// Option 1: Auto-detect (prioritizes free Gemini)
const provider = createDefaultEmbeddingProvider()

// Option 2: Explicit Gemini (free, 768 dimensions)
const gemini = new GeminiEmbeddingProvider({
  apiKey: process.env.GEMINI_API_KEY,
})

// Option 3: OpenAI (paid, higher quality)
const openai = new OpenAIEmbeddingProvider({
  apiKey: process.env.OPENAI_API_KEY,
  model: 'text-embedding-3-small', // 1536 dimensions
})
```

### 2. Vector Store

Stores and searches vector embeddings.

```typescript
import { VectorStore } from 'universal-memory-core';

const store = new VectorStore({
  storagePath: '~/.ai_memory',
  dimensions: 768, // Match your embedding provider
});

// Insert document
store.insert({
  id: 'doc-1',
  conversationId: 'conv-1',
  chunkIndex: 0,
  content: 'How to implement JWT authentication...',
  embedding: [0.1, 0.2, ...], // Generated by provider
  timestamp: Date.now(),
  sessionId: 'session-123',
  sourceFile: 'daily/2026-01-30.md',
});

// Semantic search
const queryEmbedding = await provider.generate('authentication');
const results = store.semanticSearch(queryEmbedding, 10, {
  project: 'my-app',  // Filter by project
  client: 'claude-code', // Filter by client
  minTimestamp: Date.now() - 7 * 24 * 60 * 60 * 1000, // Last 7 days
});

// Keyword search (FTS5)
const keywordResults = store.keywordSearch('authentication', 10);
```

### 3. Semantic Search

Enhanced search with time decay and project relevance.

```typescript
import { semanticSearch } from 'universal-memory-core'

const results = await semanticSearch('authentication', {
  embeddingProvider: provider,
  vectorStore: vectorStore,
  limit: 10,
  project: 'my-app',
  client: 'claude-code',
  timeRange: [startDate, endDate],

  // Weighting options
  timeDecay: true, // Enable time decay
  timeDecayHalfLife: 30, // 30-day half-life
  projectRelevance: true, // Enable project boosting
  currentProject: 'my-app', // Current project gets 1.5x boost
})
```

### 4. Hybrid Search

Combines semantic and keyword search using RRF.

```typescript
import { hybridSearch } from 'universal-memory-core'

const results = await hybridSearch('authentication', {
  embeddingProvider: provider,
  vectorStore: vectorStore,
  limit: 10,

  // RRF weights
  semanticWeight: 0.7, // 70% semantic
  keywordWeight: 0.3, // 30% keyword

  // Other options same as semanticSearch
  timeDecay: true,
  projectRelevance: true,
})
```

## Advanced Features

### Time Decay

Recent memories are ranked higher using exponential decay.

```typescript
// Formula: score * e^(-days_ago / half_life)

// 30-day half-life (default)
// - 1 day ago: score * 0.967
// - 7 days ago: score * 0.789
// - 30 days ago: score * 0.368
// - 90 days ago: score * 0.05

await semanticSearch(query, {
  timeDecay: true,
  timeDecayHalfLife: 30, // Adjust decay rate
})
```

### Project Relevance

Current project results get boosted.

```typescript
// Exact match: 1.5x boost
// Partial match (e.g., "my-app" and "my-app-api"): 1.2x boost
// Different project: 1.0x (no boost)

await semanticSearch(query, {
  projectRelevance: true,
  currentProject: 'my-app',
})
```

### Embedding Cache

Cache embeddings to reduce API calls.

```typescript
import { CachedEmbeddingProvider } from 'universal-memory-core'

const provider = new CachedEmbeddingProvider(
  new GeminiEmbeddingProvider(),
  1000 // Max cache entries
)

// Check cache performance
const stats = provider.getCacheStats()
console.log(`Hit rate: ${stats.hitRate.toFixed(1)}%`)
```

## Indexing Pipeline

Automatically index your conversation logs.

```typescript
import { IndexingPipeline } from 'universal-memory-core'

const pipeline = new IndexingPipeline(vectorStore, provider, storagePath)

// Index all daily logs
await pipeline.indexAll({
  batchSize: 20, // Process 20 conversations at a time
  skipIndexed: true, // Skip already indexed
  verbose: true, // Show progress
})

// Index recent N days
await pipeline.indexRecent(7, {
  batchSize: 5,
  skipIndexed: true,
})

// Index single conversation
await pipeline.indexConversation({
  id: 'conv-123',
  userMessage: 'How do I...?',
  aiResponse: 'To do that...',
  context: {
    timestamp: new Date(),
    project: 'my-app',
    sessionId: 'session-123',
  },
})
```

## Performance Tips

1. **Use Cached Provider**: Enable embedding cache to reduce API calls
2. **Batch Indexing**: Process multiple conversations at once
3. **Limit Results**: Use appropriate `limit` parameter
4. **Filter Early**: Apply project/client filters in search, not after
5. **Warm Cache**: Generate embeddings for common queries upfront
