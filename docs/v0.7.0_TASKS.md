### Task 2: 添加错误重试机制

**问题**: scheduler 调用 Claude CLI 失败后直接报错，无重试

**代码位置**: `packages/core/src/scheduler/lifecycle.ts:214-227`

**实现**:

```typescript
import pRetry from 'p-retry'

// 2. Extract facts using Claude CLI (with retry)
console.log('   🧠 [L0→L1] Extracting facts with Claude CLI...')
const extracted = await pRetry(
  () =>
    extractWithClaudeCLI(scanResult.conversations, {
      model: this.config.extractionModel || 'haiku',
      verbose: false,
    }),
  {
    retries: 3,
    onFailedAttempt: (error) => {
      console.warn(`   ⚠️  Extraction attempt ${error.attemptNumber} failed: ${error.message}`)
    },
  }
)
```

**步骤**:

### Task 4: 实现监控指标收集

**目标**: 收集搜索延迟、索引性能、缓存命中率等指标

**实现**:

```typescript
// packages/core/src/monitoring/metrics.ts
export class MetricsCollector {
  private metrics: Metric[] = []

  recordSearch(query: string, duration: number, resultCount: number) {
    this.metrics.push({
      type: 'search',
      query,
      duration,
      resultCount,
      timestamp: Date.now(),
    })
  }

  recordIndexing(fileCount: number, chunkCount: number, duration: number) {
    this.metrics.push({
      type: 'indexing',
      fileCount,
      chunkCount,
      duration,
      timestamp: Date.now(),
    })
  }

  getStats(): MetricsStats {
    const searches = this.metrics.filter((m) => m.type === 'search')
    const avgSearchLatency = searches.reduce((sum, m) => sum + m.duration, 0) / searches.length

    return {
      avgSearchLatency,
      totalSearches: searches.length,
      // ... 更多统计
    }
  }

  exportPrometheus(): string {
    // 导出 Prometheus 格式
  }
}
```

**集成到 MemoryManager**:

```typescript
// memory-manager.ts
async search(query: string, options: SearchOptions = {}): Promise<SearchResult[]> {
  const startTime = performance.now()

  const results = await this.searchEngine.search(query, options)

  const duration = performance.now() - startTime
  this.metrics.recordSearch(query, duration, results.length)

  return results
}
```
