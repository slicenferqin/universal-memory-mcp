## 核心卖点总结

### 6大核心特性

1. **🌍 Universal（通用）**
   - 基于 MCP 协议
   - 支持所有 AI CLI 工具
   - 一次配置，到处使用

2. **🔄 Cross-Project（跨项目）**
   - 统一管理所有项目记忆
   - 跨项目知识复用
   - 项目关联和推荐

3. **🔌 Cross-CLI（跨 CLI）**
   - 支持 Claude Code
   - 支持 OpenCode
   - 支持 Gemini CLI
   - 支持 Copilot
   - 支持所有 MCP 兼容工具

4. **🤖 Super Personal Assistant（超级个人助理）**
   - 三层记忆架构（L0/L1/L2）
   - 自动记忆整合
   - 智能搜索和召回
   - 从工具进化为伙伴

5. **🔒 Super Privacy（超级隐私）**
   - 零数据收集
   - 零遥测
   - 零分析
   - 完全加密存储

6. **💻 100% Local & Private（100%本地私有）**
   - 全部本地运行
   - 无云服务
   - 离线工作
   - 你拥有数据
